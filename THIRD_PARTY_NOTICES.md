# Ownership and third-party material

This export does not assign a new license to StableGuard or third-party material.
The repository owner must determine and add the appropriate software license
before presenting this repository as an open-source release.

The Python requirements refer to external packages including Slither,
OpenAI's Python client, PyYAML, Loguru, python-dotenv, and solc-select. Those
packages are not vendored; their own licenses apply.

The historical CSV contains audit-derived finding descriptions and code excerpts.
The evaluation JSON contains labels and source-location metadata. Public access
to an audit or repository does not establish unrestricted redistribution rights.
Review the relevant report and project terms before publication.

Full Solidity repositories, audit PDFs, downloaded dependencies, compiler
binaries, and model outputs are intentionally not bundled. Adding those materials
later requires retaining their original licenses and provenance.
