# Ownership and third-party material

This export does not assign a new license to StableGuard or to third-party material.
The repository owner must select the software license before describing the tool
as an open-source release.

`dataset/projects/` contains third-party project source and available vendored
library source. Their original license, copyright and notice files are retained
where present. Per-tree notice paths are recorded in `dataset/projects.json`.
Copying a file into this Dataset does not relicense it. A missing standalone license
file is an unresolved publication prerequisite, not unrestricted permission.

Audit-derived labels and CSV excerpts may have separate redistribution terms.
Historical internal-report references should not be described as public audits
without separate provenance confirmation. Audit PDFs are not included.

Python dependencies, installed node_modules, compiler binaries, Git histories,
environment files and model response archives are not packaged. Restore dependencies
according to the retained project locks and their own licenses. Review all applicable
terms before publishing the complete Dataset.
