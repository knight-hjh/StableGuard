# Local project inputs

Place authorized project checkouts at `dataset/<project-name>/` and run the
scanner from the repository root. Keep each project's original source layout,
compiler configuration, dependency lockfiles, and relevant dependencies.

No Solidity project repository is included in this code export. Reproducing a
historical benchmark requires the exact vulnerable or evaluated revision, not an
arbitrary current checkout. Project names alone do not identify source versions.

Everything under this directory except this README is ignored by Git. Review
redistribution rights and explicitly select any future public source snapshots.
